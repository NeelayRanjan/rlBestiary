# bestiary

An offline native artificial-life simulator with muscle-driven creatures, a persistent trait-based world, and a 3D viewer.

**MVP checkpoint:** simulation, viewer, starter zoo and recorded PNG export. The creature designer and full long-run research acceptance are still pending.

See [RUNBOOK.md](RUNBOOK.md) to build and run it, [PLAN.md](PLAN.md) for current scope, and [SPEC.md](SPEC.md) for the full roadmap.
